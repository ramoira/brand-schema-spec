# Ramoira Schema Specification

The open standard for brand identity in the agent web.

## What this is

A Ramoira brand schema is a structured, versioned,
agent-readable definition of brand identity.

It exists so that AI agents, LLMs, and automated systems
can represent a brand accurately — without hallucination,
without drift, without re-prompting.

## Who this is for

Developers building brand-aware agent workflows.
Brands who want accurate LLM representation.
Platforms building on top of Ramoira schemas.
Anyone implementing the Ramoira schema format.

## Two schema formats

brand.schema.json          Full schema. Local only.
                           All five layers. Complete detail.
                           Generated by ramoira init.
                           Never published publicly unless you share it.

brand.schema.summary.json  Summary schema. Public.
                           Identity, narrative, voice layers.
                           Enough for LLM citation accuracy.
                           Published at ramoira.com/brands/[slug]/
                           Generated by ramoira publish.

A generated schema is a candidate until the brand ratifies it.
Publishing a summary does not ratify it.

## The format specification

→ SPEC.md

SPEC.md and the JSON Schemas in this repository are normative.
Implementations, Ramoira's own included, conform to them.

Coming in 3.0.0: `certified` and `confidence` are deprecated
and will be removed. See the notice at the top of SPEC.md.
