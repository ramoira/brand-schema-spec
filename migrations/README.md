# Migrations

One guide per major version.

- [`3.0.0-to-3.1.0.md`](3.0.0-to-3.1.0.md): optional elicitation fields in `draft_provenance` (who rated, intended or current, contrast sets, retests, competitor placements). No re-ratification.
- [`3.1.0-to-3.2.0.md`](3.1.0-to-3.2.0.md): what a rule protects, governed terms, pillar ids (inside `content_hash`), and affirmations (outside it). Changing `spec_version` alone needs no re-ratification.
- [`2.0.0-to-3.0.0.md`](2.0.0-to-3.0.0.md): results removed from the schema, the rule registry, `content_hash`, situations, and a summary that no longer depends on tier.
